Written at 08:05 on 9 September.

Since yesterday a hundred and sixty-six changes merged, and then none for ten
hours: every session stopped at ten to nine last night and none resumed, so this
note is late and today's work has not begun. The main line went green at that
moment and has stayed green.

All four faults the first full rehearsal found are fixed, proved together on a
real Windows machine. The repair that undoes a bad change ran for the first time,
built the repair, and was refused permission to propose it.

The date holds at 20 September. Section four again asks the board to approve
version one's meaning, name an outside tester, and confirm September publication.
